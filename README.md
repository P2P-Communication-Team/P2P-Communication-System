
# Decentralized UDP-Based P2P Communication System

## Project Overview
A decentralized peer-to-peer application that
supports group communication and distributed
file sharing using UDP sockets.

## Main Features
- Peer discovery and membership management
- Reliable UDP communication
- Group messaging
- Distributed file storage
- Multi-source file downloads
- Fault tolerance and recovery
